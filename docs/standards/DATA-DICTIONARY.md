# Data Dictionary — schema v1

Covers every column of [`database/mobile/schema_v1.sql`](../../database/mobile/schema_v1.sql) and is the field reference for CSV / GeoJSON exports. Radio ranges and rules: [MEASUREMENT-METHODOLOGY.md](MEASUREMENT-METHODOLOGY.md). Decisions: ADR-008 (ids/time), ADR-009 (methodology versioning).

## Conventions
- **ID**: UUIDv7, lowercase hyphenated text. **Time**: UTC ISO 8601 text, e.g. `2026-10-07T14:36:00Z`.
- **Names**: `snake_case` in DB, API and export columns.
- **Nullability**: `NULL` means unavailable or not applicable, never `0`. `NOT NULL` columns are always present.
- **Booleans**: `INTEGER` 0/1 in SQLite; exported as `true`/`false`.
- **Export**: CSV uses column names verbatim; NULL is an empty field. GeoJSON puts `lon`,`lat`(,`altitude_m`) in `geometry` (Point, `[lon, lat, alt]`) and all other columns in `properties`; samples with NULL `lat`/`lon` get `geometry: null`.
- **Privacy**: no IMEI, IMSI, MSISDN, messages, contacts or photos are stored. `device_id` is a random install id.

Source key: **App** = generated by the app; **TM** = `TelephonyManager`/`CellInfo`; **LM** = `LocationManager` (ADR-006); **CM** = `ConnectivityManager`; **Build** = `android.os.Build`; **Engine** = speed/latency engine; **User** = user input.

## cell_observations
Serving and neighbour cells per sample. Fields not defined for a RAT are NULL.

| Column | Type | Unit | Null | Source | Description |
|---|---|---|---|---|---|
| observation_id | TEXT PK | UUIDv7 | no | App | |
| measurement_id | TEXT FK | UUIDv7 | no | App | → samples, cascade delete |
| is_serving | INTEGER | bool | no | TM | 1 = serving cell |
| rat | TEXT | enum | no | TM | `GSM, WCDMA, LTE, NR, CDMA, TDSCDMA` |
| mcc / mnc | TEXT | digits | yes | TM | Cell PLMN |
| lac_tac | INTEGER | – | yes | TM | LAC (2G/3G) or TAC (4G/5G) |
| cell_id | INTEGER | – | yes | TM | CID / ECI / NCI (64-bit) |
| enb_id | INTEGER | – | yes | App | LTE: `eci >> 8` |
| gnb_id | INTEGER | – | yes | App | NR: `nci >> (36 − gnb_id_length)`, default length 24 |
| local_cell_id | INTEGER | – | yes | App | LTE: `eci & 0xFF` |
| pci_psc_bsic | INTEGER | – | yes | TM | PCI (LTE/NR), PSC (WCDMA), BSIC (GSM) |
| arfcn | INTEGER | – | yes | TM | ARFCN / UARFCN / EARFCN / NR-ARFCN |
| band | TEXT | – | yes | TM / App | Band label |
| bandwidth_khz | INTEGER | kHz | yes | TM | |
| rssi_dbm | REAL | dBm | yes | TM | GSM / LTE RSSI |
| rscp_dbm | REAL | dBm | yes | TM | WCDMA |
| ecno_db | REAL | dB | yes | TM | WCDMA Ec/No |
| rsrp_dbm | REAL | dBm | yes | TM | LTE RSRP / NR SS-RSRP |
| rsrq_db | REAL | dB | yes | TM | LTE RSRQ / NR SS-RSRQ |
| sinr_db | REAL | dB | yes | TM | LTE RS-SNR / NR SS-SINR |
| cqi | INTEGER | index 0…15 | yes | TM | LTE |
| timing_advance | INTEGER | Ts units | yes | TM | LTE, 0…1282 |
| csi_rsrp_dbm | REAL | dBm | yes | TM | NR |
| csi_rsrq_db | REAL | dB | yes | TM | NR |
| csi_sinr_db | REAL | dB | yes | TM | NR |
| quality_flag | TEXT | – | yes | App | e.g. `OUT_OF_RANGE`, `UNAVAILABLE` |

Values reported as `UNAVAILABLE` (`Integer.MAX_VALUE`) or out of range are stored as NULL with `quality_flag`; never clamped.
